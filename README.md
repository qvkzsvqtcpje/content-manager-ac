## Overview

Content Manager is the premier third-party launcher for Assetto Corsa, replacing the official one with a feature-complete alternative that handles mod car and track installation, race weekend configuration, livery management, Custom Shaders Patch integration, online server browsing, replay management, and dozens of gameplay tweaks. It is effectively required by the entire competitive and modding Assetto Corsa community.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Content Manager** delivers the features you need in a clean, intuitive package.

> Official website: [assettocorsa.club](https://assettocorsa.club)

## Key Features

| Feature | Description |
|---------|-------------|
| **Mod Management** | Install, organize, and update cars and tracks from folders and archives |
| **Race Config** | Full race weekend setup with weather, time, AI, and rules configuration |
| **CSP Integration** | Deep integration with Custom Shaders Patch settings and configuration |
| **Online Browser** | Browse, filter, and join multiplayer servers directly from the launcher |
